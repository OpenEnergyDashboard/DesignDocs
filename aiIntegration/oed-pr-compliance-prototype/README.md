# OED PR Compliance Prototype

Prototype GitHub Actions for Open Energy Dashboard pull request compliance.

The prototype includes:

- AI assistance disclosure validation
- Signed CLA verification for the PR author and listed additional contributors
- CLA signing-date verification
- A proposed pull request template
